# Clifford Systems and Brauer Obstructions

Oren Ben-Bassat and Yuval Ginosar

## [Read the current manuscript (PDF)](CliffordBrauer.pdf)

We introduce a complex built from Azumaya algebras, invertible bimodules, and their isomorphisms. Its Postnikov truncation and section spaces define a 10-term exact sequence with an obstruction map to fourth group cohomology.
